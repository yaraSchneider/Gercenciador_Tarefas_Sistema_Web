# Manual do Projeto: Gerenciador de Tarefas

## Visão Geral

Este projeto é um protótipo de sistema web para gerenciar tarefas de forma organizada. Ele foi desenvolvido como parte da disciplina de Desenvolvimento de Sistemas Web.

## Autora

* **Estudante:** Yara Schneider

## Objetivo

Criar um gerenciador de tarefas com interface de usuário responsiva e recursos básicos de login, cadastro de tarefas e visualização de atividades.

## Funcionalidades Principais

- Tela de login com campos para usuário e senha
- Cadastro de novas tarefas com título e prioridade
- Visualização de tarefas em cards com status e prioridade
- Layout responsivo usando Tailwind CSS

## Tecnologias Utilizadas

- HTML5
- Tailwind CSS via CDN
- JavaScript (futuro)
- SQLite (planejado para persistência de dados)

## Estrutura do Projeto

- `index.html` - página principal do sistema
- `README.md` - documentação e manual do projeto
- `tailwind.config.js` - configuração do Tailwind CSS
- `Dicas e Truques.txt` - anotações rápidas de classes Tailwind
- `desafio_Aulas_3e4/` - pasta com desafio das aulas 3 e 4

## Uso

1. Abra o arquivo `index.html` em um navegador.
2. A tela inicial apresenta duas seções: acesso ao sistema e cadastro de tarefas.
3. A seção de login aceita usuário e senha para simular o acesso.
4. A seção de cadastro permite informar o título da tarefa e definir a prioridade.
5. Abaixo, há uma área com exemplos estáticos de tarefas.

## Observações de Desenvolvimento

- O projeto utiliza Tailwind CSS via CDN para facilitar a criação do layout.
- O formulário de login e o cadastro de tarefas estão preparados para integração com JavaScript e/ou backend.
- A persistência em SQLite ainda está planejada e não está implementada no protótipo atual.
