# Gerenciador de Tarefas

> Projeto acadêmico em desenvolvimento, construído e aprimorado ao longo das aulas.

## Sobre o projeto

Este repositório reúne o trabalho desenvolvido durante as aulas como parte de um processo contínuo de aprendizagem. A proposta é construir um projeto web aos poucos, aplicando na prática os conteúdos estudados e acompanhando sua evolução ao longo do curso.

O projeto ainda está em andamento. Por isso, esta documentação apresenta sua ideia e seu processo de desenvolvimento de forma geral, sem descrever funcionalidades específicas ou uma versão final.

## Como o trabalho é desenvolvido

Cada aula contribui para uma nova etapa do projeto. Conforme novos conteúdos são estudados, novas funcionalidades e melhorias são implementadas, e os itens já trabalhados podem ser revistos e atualizados.

Esse processo permite praticar tanto a criação de novas partes quanto a evolução do que já foi feito. Assim, o projeto cresce gradualmente junto com o aprendizado, e suas decisões podem mudar à medida que novas ideias e conhecimentos são incorporados.

## Objetivo

O objetivo é transformar os conteúdos vistos em aula em experiência prática de desenvolvimento, mantendo um projeto em constante evolução. Mais do que apresentar um produto concluído, este repositório registra as etapas, melhorias e aprendizados do percurso.

## Andamento

**Em desenvolvimento.** O conteúdo e a estrutura podem mudar conforme as próximas aulas e etapas do trabalho. Este README também poderá ser atualizado para refletir essa evolução.
